# Molsom Education Platform

A comprehensive Progressive Web Application (PWA) designed for Molsom-English bilingual education, online exams, class management, and granular permission controls.

## Features
- **Student & Teacher Portals**: Role-based access with custom permission overrides.
- **Molsom-English Dictionary & Translator**: Instant translation and interactive community word submission/approval workflow.
- **Online Classes & Material Management**: Multi-level folder creation, file uploads, and resource sharing.
- **Online Examinations & Auto-Grading**: Interactive quizzes with immediate results and leaderboard analytics.
- **PWA & Mobile Ready**: Offline caching, installable manifest, and mobile-friendly design.

## Setup & Deployment
1. Extract all files into your web root folder.
2. Open `index.html` directly in any web browser, or host via GitHub Pages, Firebase Hosting, or Vercel.
3. Integrate with Firebase by adding your Firebase credentials in the `<script>` section of `index.html`.
